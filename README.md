# Palmetto Mahjong Company

A responsive one-page website for Mahjong lessons and hosted events.

## Preview

Open `index.html` directly in a browser. No build step is required.

## Customize

- Update the contact address `hello@palmettomahjong.com` in `index.html` and `script.js`.
- Replace images in `assets/` with company photography.
- Update service details, event area, social links, and testimonial copy in `index.html`.

The contact form uses a `mailto:` link, so submissions open the visitor's configured email application. A form service or serverless endpoint can be added later for direct website submissions.
